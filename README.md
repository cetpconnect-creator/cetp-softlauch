# CETP Connect Frontend (YUKTHI X'26)

Official frontend for the YUKTHI X'26 / CETP Connect platform, built with React, Vite, and Three.js.

## Tech Stack
- **Framework**: React 18 + Vite
- **3D & Visuals**: Three.js (Starfield & Constellations)
- **Styling**: Vanilla CSS (modular stylesheets)

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
